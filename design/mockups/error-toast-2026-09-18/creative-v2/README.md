All three use the actual favourite fish screen as an attached image. Option 2 also uses the existing funds-dialog octopus as an attached character reference. The designs add soft sculpted materials, integrated ocean motifs and a heart that signals favourite protection.

## Message and behaviour

Title: This fish is a favourite

Supporting text: Unfavourite it before selling.

The toast appears after a blocked sale. It leaves the fish and favourite unchanged and includes a close control. The selected design can provide a reusable container for other error messages.

## Visual review

Each output was reviewed directly. The copy is correct and readable. Each shows one toast while keeping the fish, wallet and gameplay controls visible. The shell and bottle sit below the top HUD. The octopus sits above Done and has the largest decorative footprint. Actual generated shapes are larger than the dimensions requested in the prompts, especially the octopus. Final implementation needs responsive sizing and native live text, with a smaller decorative footprint on phones.

These are image mockups only. No app code changed, and no runtime tests were needed for this design revision.
