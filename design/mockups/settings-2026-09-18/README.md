# Approved Settings reference

`approved.png` is the clean amber-button mockup selected by the user on
18 September 2026. It was generated in the design exploration for this task.
The user supplied a screenshot of this mockup and asked to implement it.

The implementation reuses native drawing, fonts, dialog chrome and button
geometry. The mockup is a design reference, not a runtime background. All labels,
toggles, percentages and the slider are rendered and controlled by the game.
