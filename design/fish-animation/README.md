# Archived neon tetra and guppy animation trial

This trial was reverted at the user's request on 18 September 2026. The game uses
the previous neon tetra and guppy artwork and its original swimming animation.
The layered fish renderer and test tank have been removed.

These draft images, prompts and recordings are retained for reference. They are
not part of the game's packaged assets.

- `neonTetra-atlas-source.png` and `guppy-atlas-source.png`: original outputs from the built-in Image Gen tool.
- `neonTetra-prompt.md` and `guppy-prompt.md`: generation prompts using the cartoon starter-fish board as a reference.
- `alpha-cleanup-prompt.md`: attempted transparency correction. Both original sheets had opaque checkerboard backgrounds.
- `*-extraction.json`: source bounds from the sprite preparation experiment.
- `portraits/` and `preview.png`: draft assembled characters.
- `fish-animation-preview.mp4` and `fish-animation-preview.gif`: recordings of the discarded animation trial.
- `in-game.png` and `test-tank.png`: screenshots from the trial before it was reverted.
- `originals/`: the previous artwork and provenance that have been restored to `assets/species/`.
