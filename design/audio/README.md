# Background music previews

Play `coral-promenade-v3-preview.mp3` to review the current FishVille-inspired
direction for Fishius. The original 80-second tune uses marimba, flute, nylon
guitar, acoustic bass and light percussion. This revision simplifies the harmony
and removes chromatic bass pickups and competing melodic fills.

The preview has gentle opening and closing fades. Use
`assets/audio/coral-promenade-loop.wav` for seamless repetition in the game.

`coral-promenade-score.json` contains the editable note score. It uses the macOS
General MIDI instrument bank for rendering; no FishVille recording is sampled.

`coral-promenade-v3-tuning.json` contains the pitch and harmony checks.
`coral-promenade-preview.mp3` is the earlier revision 2 mix.

`lagoon-daydream-preview.mp3` is the earlier ambient draft that the user rejected.

See `assets/audio/README.md` for format details and regeneration instructions.
