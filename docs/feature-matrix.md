# Current feature status

This table describes the only active interface after the old screens and Studio editor were removed on 17 September 2026. Older reports in `evidence` and dated workbook audits describe their recorded revisions; they do not establish current UI coverage.

| Feature | Current state |
| --- | --- |
| Native aquarium, fish movement, backgrounds and existing decor | Available through Canvas and Domain |
| Feeding, care and growth | Available; feeding is free and hunger pauses growth |
| Fish purchases and repeated egg placement | Available through Shop and the placement controls |
| Fish details, favorites and selling | Available; favorites protect fish, sale rewards settle once |
| Coin, Pearl, XP and level rewards | Domain rules and persistence remain active |
| Tank switching, unlocking and capacity upgrades | Available through the porthole switcher and Shop's Tanks tab |
| Background purchases and selection | Available separately for each tank |
| Plant and decoration purchases and placement | Available through Shop; tap or drag a preview, then Place to buy and save |
| Selecting and moving plants and decorations | Available; tap to select and drag to move; each drop saves for free; tick or an outside tap ends editing and remove returns the item to inventory |
| Layout editor, stashing and restoring decorations | Dragging saves on release; tick or an outside tap ends editing; remove returns the copy to inventory; Bag groups stored copies into stacks and Place restores one copy for editing |
| Settings | Saved music, volume, effects, reduced motion and vibration; About & support page; native iOS haptics |
| Rewards | Shows repeatable pearl progress; each twenty eligible adult coin-fish sales grants one pearl automatically |
| Bag fish inventory and Projects | Fish inventory unavailable; Projects remains an empty dialog |
| Level-up dialog | Shows earned coins and pearls, delayed flights to the HUD and a horizontal mobile gallery of newly unlocked shop items |
| Collection and mastery claim screens | Old screens removed; retained domain data does not provide a current screen |
| Treasure packs | Preview only; no payment provider or checkout |
| Saves and offline care | Existing Session and Storage rules retained |
| Store release, online services and mobile performance | Not certified |

See [the current interface guide](clay-hud.md), [the workbook implementation](workbook-implementation.md) and [the save format](save-format.md). Save data, catalog prices and economy rules were not removed with the old interface.
